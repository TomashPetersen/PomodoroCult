# Assets

## Focus Music Loops

The v1.1.0 Firefox app window includes three optional local focus music loops:

- `public/sounds/focus-stream.ogg`
- `public/sounds/focus-birds.ogg`
- `public/sounds/focus-clock.wav`

Sources:

- Stream: `water_0.ogg` from OpenGameArt, "Water flowing sound", CC-BY.
  Source page: https://opengameart.org/content/water-flowing-sound
- Birds: `birds-isaiah658_0.ogg` from OpenGameArt, "Ambient Bird Sounds", CC0.
  Source page: https://opengameart.org/content/ambient-bird-sounds
- Clock: `ticking_clock.wav` from OpenGameArt, "Ticking clock.", CC0.
  Source page: https://opengameart.org/content/ticking-clock

The loops are bundled with the extension package and loaded only from the extension's local files. No remote audio requests are made.
