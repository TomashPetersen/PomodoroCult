## Full description

Pomodoro Cult is a Pomodoro timer for Firefox built for focused work sessions, local task tracking, and background countdown continuity after the popup closes.

It combines work, short break, and long rest modes with task selection and local session statistics, so you can keep one clear flow without accounts, sync setup, or external services.

Pomodoro Cult is designed to stay practical and quiet:

- Pomodoro work, break, and long rest timers
- task selection for the current work cycle
- local statistics for completed work sessions
- reliable background countdown in Firefox
- English and Russian interface
- local-first storage with no account and no cloud backend

All timer state, tasks, settings, and statistics stay in the browser's local extension storage on your device.

## Data and permissions summary

Pomodoro Cult does not collect analytics, account data, browsing history, or telemetry.

Firefox permissions used:

- `storage` - saves timer state, settings, tasks, language preference, theme, and local statistics between sessions
- `notifications` - shows a system notification when a timer completes in Firefox
- `alarms` - wakes the Firefox background runtime at the timer end time so completion handling stays reliable after the popup closes
