## Full description

Pomodoro Cult is a lightweight focus timer built for simple, repeatable work sessions.

It includes work, short break, and long rest modes, task selection for work sessions, and local statistics for completed cycles. The timer continues counting down after the popup closes, so the workflow stays intact while you browse or switch tabs.

The extension is designed to stay calm and practical:

- work, short break, and long rest timers
- automatic transition after a completed work session
- task selection for the current work cycle
- local statistics for completed sessions
- Russian and English interface
- no account, no cloud sync, no remote backend

Pomodoro Cult stores its state locally in the browser so your timer, tasks, and statistics remain available between sessions.

## Data and permissions summary

Pomodoro Cult does not collect analytics, account data, or browsing history.

Firefox permissions used:

- `storage` - saves timer state, settings, tasks, language preference, theme, and local statistics between sessions
- `notifications` - shows a system notification when a timer completes in Firefox
- `alarms` - wakes the Firefox background runtime at the timer end time so completion handling stays reliable after the popup closes
