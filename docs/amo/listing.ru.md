Минималистичный таймер фокуса с задачами, локальной статистикой и фоновым отсчетом.

## Полное описание

Pomodoro Cult — это легкое расширение с таймером фокуса для простых и повторяемых рабочих сессий.

В нем есть режимы работы, короткого перерыва и отдыха, выбор задачи для рабочего цикла и локальная статистика по завершенным сессиям. Таймер продолжает отсчет после закрытия popup, поэтому рабочий сценарий не ломается при переключении вкладок или страниц.

Расширение специально сделано спокойным и утилитарным:

- таймер работы, короткого перерыва и отдыха
- автоматический переход после завершения рабочего цикла
- выбор задачи для текущей рабочей сессии
- локальная статистика завершенных сессий
- интерфейс на русском и английском
- без аккаунта, без облачной синхронизации, без удаленного backend

Pomodoro Cult хранит свое состояние локально в браузере, поэтому таймер, задачи и статистика сохраняются между сессиями.

## Кратко про данные и permissions

Pomodoro Cult не собирает аналитику, данные аккаунта или историю просмотров.

Permissions Firefox:

- `storage` - сохраняет состояние таймера, настройки, задачи, язык, тему и локальную статистику между сессиями
- `notifications` - показывает системное уведомление Firefox после завершения таймера
- `alarms` - будит Firefox background runtime в момент окончания таймера, чтобы completion flow срабатывал надежно после закрытия popup
