## Полное описание

Pomodoro Cult — это таймер Pomodoro для Firefox, созданный для сфокусированных рабочих сессий, локального ведения задач и надежного фонового отсчета после закрытия popup.

Расширение объединяет режимы работы, короткого перерыва и отдыха с выбором задачи и локальной статистикой сессий, чтобы рабочий цикл оставался цельным без аккаунтов, облачной синхронизации и внешних сервисов.

Pomodoro Cult сделан спокойным и практичным:

- таймеры Pomodoro, короткого перерыва и отдыха
- выбор задачи для текущего рабочего цикла
- локальная статистика завершенных рабочих сессий
- надежный фоновый отсчет в Firefox
- интерфейс на русском и английском
- локальное хранение без аккаунта и без облачного backend

Состояние таймера, задачи, настройки и статистика хранятся локально в extension storage браузера на вашем устройстве.

## Кратко про данные и permissions

Pomodoro Cult не собирает аналитику, данные аккаунта, историю просмотров или телеметрию.

Permissions Firefox:

- `storage` - сохраняет состояние таймера, настройки, задачи, язык, тему и локальную статистику между сессиями
- `notifications` - показывает системное уведомление Firefox после завершения таймера
- `alarms` - будит Firefox background runtime в момент окончания таймера, чтобы completion flow срабатывал надежно после закрытия popup
