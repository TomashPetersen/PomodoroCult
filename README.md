# Pomodoro Cult

Pomodoro Cult — это Chrome Extension на `Manifest V3` с таймером Pomodoro, задачами и простой статистикой. Расширение использует `React`, `TypeScript`, `Vite`, `Zustand` и `offscreen`-документ, чтобы таймер продолжал работать даже после закрытия popup-окна.

## Что умеет проект

- запускать и останавливать рабочий таймер;
- автоматически переключать состояние между рабочей сессией и перерывами;
- привязывать сессии к задаче;
- сохранять состояние таймера, задач и статистики в `chrome.storage.local`;
- восстанавливать таймер после повторного открытия popup;
- показывать агрегированную статистику по задачам.

## Структура проекта

Ключевые файлы:

- [src/store/useAppStore.ts](D:\Projects\MyProjects\PomodoroCult\src\store\useAppStore.ts) — основной Zustand-store для popup-интерфейса. Здесь живут hydration, действия пользователя и синхронизация UI с `chrome.storage`.

- [src/offscreen.ts](D:\Projects\MyProjects\PomodoroCult\src\offscreen.ts) — offscreen-документ, который поддерживает живой отсчет и completion chime вне popup-окна.

- [src/lib/types.ts](D:\Projects\MyProjects\PomodoroCult\src\lib\types.ts) — основные типы, runtime-сообщения и константы.
- [src/components](D:\Projects\MyProjects\PomodoroCult\src\components) — экран таймера, задачи, статистика, навигация и настройки.
- [manifest.json](D:\Projects\MyProjects\PomodoroCult\manifest.json) — описание расширения и его permissions.

## Как работает таймер

Архитектура таймера разделена на три слоя:

1. Popup (`useAppStore.ts`) отправляет команды `start`, `pause`, `reset` и отображает текущее состояние.
2. `background.ts` принимает команды popup, проверяет данные, создает `offscreen`-документ при необходимости и обновляет глобальное состояние.
3. `offscreen.ts` выполняет сам отсчет, периодически пишет `timerState` в `chrome.storage.local`, а по завершении уведомляет background о конце сессии.

Такой подход нужен потому, что popup Chrome-расширения уничтожается после закрытия окна, а `offscreen`-документ позволяет поддерживать отсчет независимо от popup.

## Данные и хранение

Расширение хранит данные в `chrome.storage.local`:

- `settings`
- `tasks`
- `timerState`
- `statistics`
- `theme`

Это позволяет восстановить состояние интерфейса и таймера между открытиями расширения.

## Permissions и модель безопасности

Сейчас проект использует только два permission:

- `storage` — для сохранения состояния таймера, задач и статистики;
- `offscreen` — для фонового отсчета через offscreen-документ.

Проект не использует внешние API, не отправляет пользовательские данные на сервер и не добавляет произвольные `host_permissions`.

Runtime-коммуникация ограничена внутренними сообщениями расширения через `chrome.runtime.sendMessage`.

## Известные ограничения и текущие риски

На текущем этапе в проекте есть несколько известных проблем, которые стоит исправить в ближайших изменениях:

1. В части файлов есть поврежденные русские строки интерфейса. Это приводит к mojibake-тексту в UI и ухудшает доступность.
2. Поведение табов таймера может вводить в заблуждение: короткий и длинный перерыв можно выбрать визуально, но управление таймером фактически ориентировано только на рабочую сессию.
3. Ошибки `chrome.runtime.sendMessage` и инициализации `offscreen` сейчас не выводятся пользователю явно, поэтому часть runtime-сбоев будет выглядеть как “ничего не произошло”.
4. Пользовательские строки и ограничения вроде максимальной длины названия задачи распределены по нескольким файлам, что усложняет сопровождение.
5. В проекте пока нет автоматических тестов уровня бизнес-логики и UI.
